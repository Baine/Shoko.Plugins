TMDB Link Fixer

Checks existing links and helps you compare replacements. Nothing is replaced from a scan or search result; an administrator must review one exact candidate and explicitly confirm it.

TMDB API validation

Bulk checks use the TMDB API, never the public website. Enter a v3 API key or v4 read access token. Leaving the credential field empty keeps the saved value.
