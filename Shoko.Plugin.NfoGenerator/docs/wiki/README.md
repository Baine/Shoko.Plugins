# Maintainer Wiki

This is compact, durable context for humans and coding agents working on NFO Generator. It complements user documentation, source code, release notes, and `AGENTS.md`.

## Use it

1. Start at [the index](INDEX.md).
2. Read the relevant page before changing that subsystem.
3. Update the relevant page with any non-obvious invariant, operational lesson, or integration detail established by a change.
4. Keep pages factual and concise; link to code rather than copying details likely to drift.

User-facing behavior belongs in `README.md` and `docs/`; agent instructions and build/release rules belong in `AGENTS.md`. Do not add chat transcripts, secrets, host-specific paths, or temporary debugging output.
